# 08-OLED-LDR-Display

An ESP32-based light monitoring project that reads an LDR sensor and displays the live reading on an SSD1306 OLED display.

## Features

- LDR light sensor
- SSD1306 OLED display
- Live light-level reading
- ESP32-based system
- Wokwi simulation

## Output

The LDR reading is displayed on the OLED and printed in the Serial Monitor.
