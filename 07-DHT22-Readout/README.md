# 07-DHT22-Readout

An ESP32-based temperature and humidity monitoring project using a DHT22 sensor, simulated in Wokwi.

## Features

- DHT22 temperature measurement
- DHT22 humidity measurement
- Serial Monitor output
- Readings updated every 2 seconds
- Wokwi simulation

## Output

The Serial Monitor displays temperature in °C and humidity in %.
