# 06-Web-Controlled-LED

An ESP32-based web-controlled LED project simulated in Wokwi.

The ESP32 connects to WiFi and hosts a simple web server with ON and OFF controls for the LED.

## Features

- ESP32 WiFi connection
- HTTP web server
- Remote LED ON/OFF control
- Wokwi simulation
